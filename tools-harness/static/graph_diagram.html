Deterministic Search Graph Flow

ENTRY

START / GUARD

Input validation, safety checks, and clarification routing.

↓

DECOMPOSE

Handles multi-hop queries. Executes hop-1 inline to resolve entities for hop-2.

↓

REWRITE

Query expansion. Generates 2-3 variants (verbatim, condensed, temporal).

↓
PARALLEL

DISCOVERY (FETCH)

Wiki, RSS, and domain-specific knowledge retrieval.

PARALLEL

DDG SEARCH

Live web search for fresh snippets (No-API fallback).

↓

MERGE RESULTS

Deduplication and authority-weighted ranking of parallel branches.

↓ (Success)

NORMALIZE + DEDUPE

Clean raw results and strip duplicate URLs.

↓ (Fail)
FALLBACK

EXA + BRAVE

Secondary search backends for high-recall retrieval.

↓

REDDIT AUGMENT

Injects Reddit threads if snippets are "thin" or low-recall.

↓

RERANK (LLM)

Cross-encoder scoring to select the top 3 evidence bundles.

↓

EVIDENCE PACK

Bundles metadata (trust scores, dates) into the prompt context.

↓
OUTPUT

SUMMARIZE (LLM)

Model-driven answer generation with source-grounded reasoning.

↓

VERIFY

Checks for premise mismatches and stale temporal data.

↓
EXIT

FINALIZE

Citation formatting, staleness caveats, and final response emission.
