Deterministic Search Graph Flow

A high-precision retrieval pipeline for live web answers

Execution Pipeline
1. Guard & Decompose

Safety checks + Multi-hop sub-query resolution.

↓
2. Rewrite

Generates 2-3 targeted search variants (verbatim, condensed, temporal).

↓
3a. Discovery (Fetch)

Wikipedia / RSS retrieval.

3b. DDG Search

Live web snippets (No-API).

↓
4. Merge & Fallback

Deduplication. Triggers Exa/Brave if primary fails.

↓
5. Refinement (Normalize → Rerank)

Cross-encoder scoring (top 3) + Reddit augmentation.

↓
6. Summarize & Verify

LLM-driven grounded answer generation + Hallucination checks.

↓
7. Finalize

Citation formatting + Staleness caveats.
